# SG Client 099

SG Client 099 — крупное обновление Windows-клиента с новым поколением runtime, расширенной поддержкой протоколов и переработанной логикой подключения.

## Главное

- Совместимость с новым ядром Xray и актуальными Xray-сценариями, включая VLESS, REALITY, TLS и XHTTP.
- Полноценная поддержка AmneziaWG 2.0, AmneziaWG 3.0 и AmneziaWG 3.1 как отдельных профилей.
- Исправлена работа AmneziaWG 3.1 в TUN-режиме, включая DNS, UDP/QUIC и переключение между профилями.
- Переработан Ads=Block для AWG: блокировка рекламы теперь применяется на уровне маршрутизации трафика, а не только DNS-фильтрации.
- Полноценная поддержка Mieru и NaiveProxy.
- Mihomo обновлён до v1.19.30.
- Добавлено безопасное обновление Mihomo из клиента: проверка версии и SHA-256, резервная копия предыдущего ядра и автоматический rollback при ошибке.
- Kill Switch включён по умолчанию и больше не сбрасывается после команды «Отключить всё».
- Исправлено определение реально активного подключения: интерфейс и статистика теперь относятся к фактически работающему профилю, а не к предыдущей выбранной ноде.

## Стабильность подключения

- Исправлена синхронизация состояния между обычными профилями и AWG.
- Исправлено отображение активного AWG-профиля после переключения и обновления интерфейса.
- Исправлена атрибуция статистики трафика для AWG.
- После полного отключения клиент больше не показывает последнее соединение как активное.
- Доработана логика остановки runtime и взаимодействия с Windows Firewall.

## Runtime и сборка

- В Portable-сборке сохраняется полный комплект необходимых ядер и runtime-файлов: Xray, sing-box, Mihomo, AmneziaWG и сопутствующие данные.
- Усилен контроль комплектности сборки, чтобы публикационный пакет не мог превратиться в неполный .NET publish без runtime-компонентов.
- Добавлены проверки manifest и SHA-256, валидация XAML, ZIP CRC и контроль обязательных файлов.
- Усилен Windows-builder и исправлены проблемы сборки, связанные с generated paths и длинными путями Windows.

## Интерфейс

- Публичное обозначение версии приведено к `099`.
- Активный профиль отображается вместе с фактическим протоколом, например `Имя · AmneziaWG 3.1`.
- Центральный блок подключения очищается после полного отключения, при этом выбранный профиль и накопленная статистика сохраняются.
- Упрощены отдельные элементы маршрутизации и служебная информация.

## Формат выпуска

SG Client 099 распространяется как Portable-сборка для Windows x64.

Скриншоты и финальные файлы релиза будут добавлены после окончательной проверки публикационной сборки.
