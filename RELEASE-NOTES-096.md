# SG Client v0.0.96

## Mihomo and Mieru

SG Client 096 adds Mihomo as a runtime engine and supports simple `mierus://` links.

Supported Mieru data includes:

- TCP and UDP;
- a single port, repeated port bindings and port ranges;
- username and password;
- multiplexing;
- traffic pattern;
- import, export, duplicate comparison and latency handling.

Mieru profiles participate in the existing SG Client connection modes and routing model:

- TUN;
- System Proxy;
- Local Proxy;
- VPN / Direct / Block routing.

## Luxury Jade Depth

The light theme was rebuilt as a layered interface rather than a flat recolor:

- pale jade and pearl background;
- ivory and warm-stone surfaces;
- jade primary actions;
- restrained champagne accents;
- soft vertical gradients;
- separate button and card shadow depths;
- subtle upper highlight edges;
- raised toolbar, profile card, traffic card, mode buttons, tiles and popup menus.

The original Graphite and Northern palettes remain unchanged. The rejected experimental Dark Depth version is not included.

## Preserved functionality

The release keeps the stable SG Client 095 foundation:

- Xray-core, sing-box and AmneziaWG support;
- VLESS REALITY / TLS, raw/TCP and XHTTP;
- Hysteria 2 and compatible sing-box profiles;
- TUN, System Proxy and Local Proxy;
- tray controls;
- subscriptions and flexible import;
- SG Smart Routing and GeoFiles;
- RoscomVPN-compatible GeoFiles handling;
- live Connections and route diagnostics;
- per-profile traffic statistics;
- backup, restore, maintenance and logs.
