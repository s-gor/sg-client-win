# Changelog

## SG Client 099F

Большое обновление после публичной версии 096.

### Добавлено и улучшено

- полноценная поддержка AWG2/AWG3 в SG-native подписках;
- корректное обновление и удаление subscription-owned AWG-профилей без дублей;
- расширенная интеграция Mihomo: Mieru TCP/UDP, AnyTLS, TUIC v5;
- реальная проверка задержки для Mieru UDP, TUIC v5, AnyTLS и AWG2/AWG3;
- ускоренная массовая проверка профилей без блокировки обычных серверов долгими AWG-проверками;
- RU White List для Xray, sing-box, Mihomo и AmneziaWG;
- поддержка пользовательской маршрутизации `geosite:category-ru` / `geoip:ru` → Direct;
- Kill Switch включён по умолчанию для новых установок и добавлена безопасная миграция старых настроек;
- улучшены карточки профилей, protocol badges и подсчёт профилей внутри подписок;
- исправлена обработка граничных IPv4/IPv6 CIDR;
- добавлена автоматическая адаптация интерфейса под низкие разрешения и разные DPI;
- обновлено ядро Xray;
- подготовлен очищенный Portable без пользовательских данных, тестовых логов, кэшей и backup-дублей GeoFiles.

### Совместимость

Сохранены TUN, System Proxy, Local Proxy, SG Smart Routing, GeoFiles, диагностика маршрутов, мониторинг соединений, статистика трафика, резервное копирование, темы интерфейса и ручной импорт AmneziaWG.
