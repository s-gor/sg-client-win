# SG Client 099K — SMART-подключение, автоматический резерв и реальная проверка VPN

Полное описание основных изменений находится в этом документе, а подробные инструкции вынесены отдельно:

- [полная справка по политикам, SMART и failover](docs/099K-POLICIES-GUIDE.md);
- [темы «Пепел» и «Сталь»](docs/099K-THEMES-GUIDE.md).

> Полный развёрнутый текст релиза сохраняется в истории ветки. Перед финальной публикацией этот файл будет собран в окончательную release-версию вместе с проверенным Portable.

## Главное в 099K

- реальная DNS- и HTTPS-проверка через TUN;
- отдельные состояния запуска, проверки, стабильной работы, нестабильности и переключения;
- автоматические failover-политики с основным профилем и упорядоченными резервами;
- пошаговый мастер и пять готовых сценариев;
- SMART для SG-подписок по протоколам без ping;
- SMART для обычных подписок по задержке с последующей реальной проверкой через TUN;
- Kill Switch во время проверки и переключения;
- отдельные AWG 2.0, AWG 3.0 и AWG 3.1;
- пакетное удаление выбранных профилей и нод;
- безопасное сохранение существующей маршрутизации при failover;
- видимый прогресс ручных и массовых проверок;
- две дополнительные тёмные темы: «Пепел» и «Сталь».

## Реальная проверка VPN

SG Client больше не считает запущенное ядро или созданный TUN доказательством рабочего соединения.

```text
Запуск ядра
→ создание TUN
→ DNS через TUN
→ HTTPS через TUN
→ подтверждённое подключение
```

Если серверный пользователь удалён, ключ отозван или сервер перестал пропускать трафик, клиент не оставляет ложный зелёный статус.

## Автоматическое переключение

Политика содержит основной профиль или группу протоколов и последовательность резервов. При подтверждённом отказе текущего соединения клиент сохраняет защиту Kill Switch, останавливает нерабочий профиль, запускает следующего кандидата и подтверждает его через DNS и HTTPS.

Доступны интервал проверки, порог последовательных ошибок, тайм-аут, cooldown, задержка перехода, лимит переключений и автоматический возврат на основной вариант.

## SMART-политики

Для SG-подписок пользователь выбирает до трёх протоколов в порядке приоритета. Ping не применяется.

Для обычных подписок задержка используется только для предварительного выбора до трёх кандидатов. Рабочим считается только профиль, который прошёл фактическую DNS- и HTTPS-проверку через TUN.

## Пакетное удаление

Поддерживаются `Ctrl + клик`, `Shift + клик`, `Ctrl + A` и единое подтверждение удаления выбранных профилей или нод подписки.

## Маршрутизация

Основная модель маршрутизации не заменялась:

```text
Direct — напрямую
VPN — через активный профиль
Block — блокировка
```

SMART выбирает профиль, failover безопасно переключает его, а существующая маршрутизация распределяет трафик через новый активный профиль.

## Новые темы

В дополнение к «Графиту», «Латте» и «Северу» добавлены:

- **Пепел** — нейтральная тёмно-серая тема без выраженной синевы, с мягкими поверхностями и сдержанным нефритовым акцентом;
- **Сталь** — холодная серо-стальная тема с более заметными границами, повышенным контрастом и стально-синим акцентом.

Обе темы имеют отдельные цвета окон, карточек, полей, таблиц, кнопок и состояний hover, pressed, selected и disabled. Выбор сохраняется после перезапуска.

## Публикация

Планируется один основной файл релиза: `SG-CLIENT-099K-PORTABLE.zip`. Соответствующие исходники должны быть закреплены тегом `v0.0.99K` в репозитории. Отдельные SOURCE и FULL-BUILD-KIT архивы не требуются.

Финальный Portable публикуется только после Windows-сборки и контрольной проверки архива.
