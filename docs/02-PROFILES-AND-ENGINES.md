# Профили и движки

SG Client определяет тип импортированного профиля и выбирает подходящий движок автоматически.

| Профиль | Основной движок |
|---|---|
| VLESS RAW/TCP + REALITY | Xray |
| VLESS XHTTP + REALITY | Xray |
| VLESS XHTTP + TLS | Xray |
| Hysteria 2 | sing-box |
| Mieru TCP / UDP | Mihomo |
| AnyTLS | Mihomo / совместимый sing-box путь |
| TUIC v5 | Mihomo / совместимый sing-box путь |
| AmneziaWG 2.0 | AmneziaWG |
| AmneziaWG 3.0 | AmneziaWG |

## Проверка задержки

Обычные Xray/sing-box профили проверяются штатным core-based путём. Для Mihomo-профилей используется реальный временный профиль, поэтому UDP-only Mieru и TUIC v5 проверяются через фактический transport, а не обычным TCP-connect.

AWG2/AWG3 проверяются отдельно через кратковременно поднятый AmneziaWG-туннель. Если Windows ещё не успел подготовить интерфейс, peer или маршрутизацию, SG Client делает внутреннюю повторную попытку без промежуточной пользовательской ошибки.

## SG-native подписки

SG-native формат может содержать обычные URI-профили и полные AWG2/AWG3 конфигурации. При обновлении подписки принадлежащие ей AWG-профили обновляются по стабильному идентификатору и не дублируются.

Проект ориентирован на SG-Panel, SG-AWG-Panel и SG Gateway, но совместимые сторонние профили также поддерживаются.
