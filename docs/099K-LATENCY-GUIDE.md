# SG Client 099K FIX6 — индикация проверки задержки

## Где находится проверка

В списке профилей нажмите **«Проверить задержку»** и выберите:

- **Показанные профили** — проверяются только элементы, оставшиеся после поиска и фильтров;
- **Все профили** — проверяется полный список.

## Отдельная панель прогресса

После запуска над нижней панелью действий появляется отдельный блок **«Проверка задержки»**.

Он показывает:

- анимированную полосу до первого результата;
- точный процент после появления первого завершённого измерения;
- количество проверенных профилей;
- общее количество профилей;
- число профилей, которые ответили;
- текущую или последнюю обработанную ноду;
- кнопку **«Остановить»**.

Основная кнопка внизу во время операции содержит только короткую подпись **«Проверяется…»**. Длинный счётчик больше не помещается внутрь кнопки и не обрезается.

## После завершения

Панель не исчезает автоматически. Она остаётся на экране и показывает итог:

- сколько профилей ответили;
- сколько не поддерживают измерение;
- сколько недоступны;
- сколько завершились ошибкой;
- сколько не было проверено.

При наличии проблем появляется кнопка **«Проблемные»**, которая оставляет в списке только элементы без успешного результата.

## Остановка проверки

После нажатия **«Остановить»**:

1. новые измерения не запускаются;
2. уже выполняющиеся операции завершают отмену;
3. панель показывает фактически обработанное количество;
4. непроверенные элементы получают явный статус;
5. итог остаётся видимым.

## Что означает «Ответили»

Счётчик **«Ответили»** увеличивается только для профилей, по которым получена успешная задержка. Профили без поддержки измерения, недоступные узлы и ошибки в этот счётчик не входят.

## Задержка и реальная работа VPN

Проверка задержки используется для оценки и предварительного выбора профилей. Она не заменяет проверку реального VPN-доступа.

После подключения SG Client отдельно проверяет:

- наличие TUN-интерфейса;
- DNS через TUN;
- HTTPS через TUN.

Низкая задержка не гарантирует рабочее VPN-соединение.
