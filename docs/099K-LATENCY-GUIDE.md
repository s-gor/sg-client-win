# SG Client 099K FIX7 — проверка задержки

## Где запускается проверка

В списке профилей нажмите **«Проверить задержку»** и выберите:

- **Показанные профили** — проверяются элементы, оставшиеся после поиска и фильтров;
- **Все профили** — проверяется полный список.

## Компактная индикация

Во время проверки в нижней части списка появляется компактная накладка. Она не занимает отдельную высокую карточку и не уменьшает полезную область списка.

Накладка показывает:

- количество завершённых проверок и общее количество профилей;
- текущий процент;
- число профилей, которые ответили;
- текущую обрабатываемую ноду;
- заметную кнопку остановки `×`.

До получения первого результата по шкале движется короткий светящийся сегмент. После начала обработки результатов шкала заполняется в соответствии с фактическим процентом.

Основная кнопка сохраняет подпись **«Проверить задержку»** и блокируется на время операции. Длинный служебный текст внутрь кнопки больше не помещается.

## Индикация в строках профилей

Маленький движущийся индикатор отображается только у профиля, который фактически проверяется в данный момент.

После завершения измерения строка сразу показывает результат:

- задержку в миллисекундах;
- `Недоступна`;
- `Не поддерживается`;
- `Ошибка`.

Профили, которые только ожидают своей очереди, не получают ложную надпись `Проверяется…`.

## После завершения

Большая накладка исчезает и заменяется компактной итоговой строкой:

```text
Проверка завершена · ответили 286 из 419 · проблемные 133
```

Итог остаётся видимым до следующего запуска проверки или изменения списка. При наличии неуспешных результатов доступна команда **«Проблемные»**.

## Остановка проверки

После нажатия `×`:

1. новые измерения перестают запускаться;
2. выполняющиеся операции получают отмену;
3. отображается фактически обработанное количество;
4. непроверенные элементы не выдаются за завершённые;
5. итог остаётся доступен в компактной строке.

## Что означает «Ответили»

Счётчик **«Ответили»** увеличивается только для профилей, по которым получена успешная задержка. Недоступные профили, ошибки и неподдерживаемые способы измерения в этот счётчик не входят.

## Задержка и работоспособность VPN

Проверка задержки нужна для предварительной оценки и выбора кандидатов. Она не подтверждает работоспособность VPN.

После фактического подключения SG Client отдельно проверяет:

- создание TUN-интерфейса;
- DNS через TUN;
- HTTPS через TUN.

Низкая задержка сама по себе не гарантирует рабочее VPN-соединение.
