# Проверка задержки — FIX8/FIX9/FIX10

В списке профилей команда **«Проверить задержку»** запускает проверку показанных или всех профилей.

## Индикация

Компактная накладка внизу списка показывает:

- `X из Y` и процент;
- количество ответивших;
- текущую ноду;
- движущуюся шкалу;
- кнопку остановки `×`.

До первого результата движется светящийся сегмент. Затем шкала заполняется по фактическому проценту. Только реально проверяемая строка получает анимацию.

После завершения остаётся компактная итоговая строка с количеством ответивших и проблемных профилей.

## Сортировка

В режиме **«Задержка: быстрее»** уже ответившие ноды переставляются во время проверки. Самая быстрая из подтверждённых нод поднимается вверх до завершения полного списка.

## Важно

Задержка служит для оценки и предварительного выбора. Рабочий VPN подтверждается отдельно: предварительная проверка сервера, затем DNS и HTTPS через TUN.
