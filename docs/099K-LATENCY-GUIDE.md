# SG Client 099K FIX8 — работающая индикация проверки задержки

## Что было неисправно

В FIX7 сама проверка задержки запускалась, но визуальная индикация не появлялась.

Причина находилась не в анимации и не в механизме измерения. `ProfilesView` создавал собственный `ProfilesViewModel`, однако не назначал его своим `DataContext`. Поэтому обычные WPF-привязки накладки искали свойства `LatencyTest*` в чужом или пустом контексте.

В результате:

- проверка выполнялась;
- строки могли получать результаты;
- компактная накладка оставалась скрытой;
- процент, счётчики, текущая нода и кнопка остановки не обновлялись.

## Что исправлено в FIX8

Сразу после создания модели представления выполняется явное назначение:

```csharp
ViewModel = new ProfilesViewModel(UpdateViewHandler);
DataContext = ViewModel;
```

Теперь накладка и итоговая строка получают реальные состояния:

- запуск проверки;
- количество завершённых профилей;
- общее количество;
- процент;
- число ответивших;
- текущую ноду;
- состояние остановки;
- итог после завершения или отмены.

Предсборочная проверка также требует наличие этого назначения и не пропустит повтор дефекта.

## Где запускается проверка

В списке профилей нажмите **«Проверить задержку»** и выберите:

- **Показанные профили** — только элементы после поиска и фильтров;
- **Все профили** — полный список.

## Как выглядит работающая индикация

Во время проверки в нижней части списка появляется компактная накладка. Она показывает:

- `X из Y`;
- фактический процент;
- количество ответивших профилей;
- текущую проверяемую ноду;
- кнопку остановки `×`.

До первого результата движется короткий светящийся сегмент. После появления результатов шкала заполняется по фактическому проценту.

Маленькая анимация отображается только у профиля, который проверяется в данный момент. Ожидающие профили не получают ложный статус `Проверяется…`.

## После завершения

Накладка заменяется компактной итоговой строкой:

```text
Проверка завершена · ответили 286 из 419 · проблемные 133
```

При наличии неуспешных результатов доступна команда **«Проблемные»**.

## Задержка и работоспособность VPN

Измерение задержки используется только для предварительной оценки профилей. Работоспособность VPN отдельно подтверждается проверкой TUN, DNS и HTTPS через туннель.
