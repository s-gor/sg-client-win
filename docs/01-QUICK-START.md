# Быстрый старт

1. Скачайте Portable ZIP из GitHub Releases.
2. Полностью распакуйте архив в отдельную папку.
3. Запустите `SG-Client.exe`.
4. Импортируйте ссылку, профиль или подписку.
5. Выберите профиль.
6. Включите нужный режим: TUN, System Proxy или Local Proxy.
7. Дождитесь рабочего состояния подключения.

Для AmneziaWG поддерживаются AWG2/AWG3, в том числе профили из SG-native подписок.

При первом запуске Windows может запросить разрешение администратора для функций, которым оно требуется.
