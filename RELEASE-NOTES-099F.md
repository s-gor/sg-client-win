# SG Client 099F

SG Client 099F — крупное обновление после публичной 096. Основные изменения затрагивают SG-native подписки, AmneziaWG, Mihomo-профили, проверку задержки, RU White List, Kill Switch, карточки профилей, обработку CIDR и адаптацию интерфейса под небольшие экраны.

## Профили и движки

После 096 расширена интеграция Mihomo:

- Mieru TCP / UDP;
- AnyTLS;
- TUIC v5;
- отдельная генерация реального speed-test профиля для этих типов подключений.

AnyTLS и TUIC v5 также сохраняют совместимый sing-box путь там, где он применим.

## SG-native подписки и AWG2/AWG3

SG Client теперь понимает SG-native подписку, в которой вместе с обычными URI-профилями могут передаваться полные конфигурации AmneziaWG.

Поддерживается:

- AWG2 и AWG3;
- `device_id` как строка или число;
- стабильная привязка AWG-профиля к подписке;
- обновление существующего AWG-профиля без создания дубля;
- принятие совпадающего локального AWG-профиля в подписку;
- удаление принадлежащих подписке AWG-профилей при удалении подписки;
- очистка stale subscription-owned AWG записей, если тот же источник успешно переключён на compatible/bare feed, где SG-CONFIG больше нет;
- сохранение обычного ручного импорта AmneziaWG без изменений.

Для полностью настроенного одного устройства SG-native подписка может объединять обычные URI-профили с AWG2 и AWG3 в одном источнике.

## Проверка задержки

Система проверки задержки расширена для профилей, которые нельзя корректно оценивать обычным TCP-connect.

### Mihomo / UDP / QUIC

Для Mihomo-профилей SG Client поднимает временный локальный профиль и измеряет соединение через него. Это позволяет корректно проверять:

- Mieru TCP;
- Mieru UDP, включая UDP-only конфигурации;
- TUIC v5 через реальный QUIC/UDP transport;
- AnyTLS через фактический профиль.

### AWG2 / AWG3

Для AmneziaWG реализован отдельный Windows RTT probe через кратковременно поднятый AWG-туннель. Это не ICMP-проверка и не время запуска процесса — измерение выполняется после готовности data-plane.

Проверка учитывает реальную последовательность готовности Windows:

- запуск временного AWG service;
- ожидание состояния RUNNING;
- ожидание Wintun/UAPI и peer;
- ожидание готовности data-plane;
- измерение сетевой задержки после готовности туннеля;
- обязательная очистка временного туннеля после проверки.

Временные startup-сбои считаются retryable. Пользователь не получает промежуточную ошибку: SG Client автоматически выполняет одну повторную попытку с расширенными окнами ожидания.

Чтобы общая проверка списка не тормозила из-за AWG, обычные Xray/sing-box/Mihomo профили проверяются раньше AWG. Первый AWG-проход использует короткие адаптивные окна, а длинное ожидание включается только после реального transient startup failure.

## RU White List

Добавлен режим:

**«Белый список РФ напрямую, остальное через VPN»**.

В поставляемом snapshot используются:

- 613 доменных правил;
- 78 точечных CIDR-сетей.

В этот режим намеренно не входит весь `geoip:ru`. Полный российский GeoIP остаётся отдельным режимом маршрутизации.

RU White List поддерживается Xray, sing-box, Mihomo и AmneziaWG.

Для AmneziaWG точечные CIDR исключаются из tunnel AllowedIPs, а доменные правила разрешаются в текущие публичные адреса и получают временные Direct-маршруты. Созданные SG Client маршруты отслеживаются и удаляются при отключении, ошибке подключения и аварийной остановке; доменные адреса обновляются при следующем подключении.

В комплект включён заранее проверенный snapshot. Сборочный launcher может обновить набор перед публикацией; если обновление недоступно или не проходит валидацию, сохраняется проверенная встроенная копия.

## Kill Switch

- для новых настроек Kill Switch включён по умолчанию;
- при первом чтении старой конфигурации 099D/099E состояние переводится в ON один раз;
- после миграции пользователь может выключить Kill Switch, и этот выбор сохраняется после перезапуска;
- добавлен marker миграции и regression-тесты для обоих сценариев.

## Карточки профилей

Обновлено отображение списка профилей:

- служебные protocol suffixes убираются только из отображаемого имени;
- технология показывается отдельным компактным badge;
- измеренная задержка остаётся отдельным значением;
- AWG2/AWG3 показываются собственными badge;
- endpoint AWG не перегружает карточку лишней информацией;
- количество профилей считается внутри выбранного источника/подписки.

Исходные Remarks и параметры подключения при этом не изменяются.

## Поддержка низкого разрешения и DPI

Добавлено адаптивное масштабирование интерфейса:

- на рабочей области 1600×900 и выше используется обычный масштаб 100%;
- уменьшение интерфейса включается только на действительно небольших экранах;
- ручное изменение размера окна не приводит к постоянному уменьшению всего UI;
- при переносе окна между мониторами масштаб пересчитывается;
- Windows DPI 125/150% на нормальном мониторе не должен ошибочно включать low-resolution режим.

## CIDR и надёжность маршрутов

Исправлена checked-overflow ошибка при построении масок IPv4/IPv6 CIDR. Добавлены проверки граничных префиксов IPv4 `/0…/32` и IPv6 `/0…/128`.

Исправление применяется в AWG RU White List и связанных route diagnostics без изменения обычного AmneziaWG connect/disconnect path.

## Runtime и Portable

- обновлено ядро Xray;
- сохранены рабочие sing-box, Mihomo, AmneziaWG, GeoFiles и SRS runtime-компоненты;
- финальный Portable очищен от тестовых логов, временных `configTest*.json`, пользовательской базы, профилей, latency-cache и backup-дублей GeoFiles;
- новый Xray в финальном Portable сохранён без замены при очистке.

Формат распространения остаётся прежним: распаковать Portable ZIP и запустить `SG-Client.exe`.

## Сохранено без регрессий

099F сохраняет основные возможности 096 и более ранних сборок:

- TUN, System Proxy и Local Proxy;
- SG Smart Routing;
- live Connections и route diagnostics;
- GeoFiles;
- статистику трафика по профилям;
- резервное копирование и восстановление;
- управление из трея;
- темы Graphite, Northern и Luxury Jade;
- ручной импорт AmneziaWG;
- Xray, sing-box и Mihomo connection paths.
