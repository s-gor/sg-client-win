# SG Client 100

SG Client — Windows-клиент для современных VPN и proxy-подключений с единым интерфейсом.

## Что изменилось в версии 100

- AnyTLS адаптирован под Single Edge и общий внешний порт 443.
- Добавлена корректная работа с `alpn=sg-anytls`.
- Исправлена совместимость AnyTLS с текущей схемой SG.
- Исправлена работа Mieru после обновления sing-box.
- Устранён конфликт второго Clash controller при запуске дополнительного sing-box.
- Доработан preflight профилей: один неудачный URL больше не является единственным критерием доступности.
- Добавлена проверка через несколько независимых HTTPS probe.
- Доработана совместимость VLESS Reality с новыми версиями Xray.
- Исправлена работа Reality-профилей с `fp=edge` на новых версиях Xray.
- Улучшено отображение вкладки «Статус»: при отсутствии runtime-данных больше не показываются ложные нули.
- Кнопка массового теста задержки сделана понятнее.
- Убраны лишние и неработающие элементы интерфейса.
- Упрощена работа с подписками.
- Обновлены сетевые ядра.
- Обновлены GeoIP/GeoSite и связанные наборы правил.

## Поддерживается

- Xray
- sing-box
- Mihomo
- Mieru
- AmneziaWG / AWG 3.1
- VLESS / Reality / XHTTP
- AnyTLS
- TUN Mode
- System Proxy
- Local Proxy
- GeoIP / GeoSite / SRS routing

## Установка

SG Client распространяется как Portable-сборка.

1. Распакуйте ZIP в отдельную папку.
2. Запустите `SG-Client.exe`.
3. Импортируйте ссылку, профиль или подписку.
4. Выберите нужный режим подключения.

Windows 10/11 x64.

## Публичная сборка

В публичной сборке отсутствуют пользовательские профили и подписки.

Сохранены:
- актуальные сетевые ядра;
- GeoIP/GeoSite;
- правила маршрутизации;
- DNS и routing-настройки;
- темы и остальные рабочие компоненты клиента.

Служебные логи, временные runtime-конфиги и старые резервные копии ядер удалены из публичного архива.

## Диагностика

Если профиль не подключается, для проверки желательно приложить:
- формат ссылки или конфигурации;
- название протокола;
- несколько строк журнала сразу после попытки подключения;
- используемый режим: TUN / System Proxy / Local Proxy.
